

Below are the steps to generate the chrf++ score :
    -> Keep the structure of predicted csv and ground truth files same as the test.csv file provided.
    -> Replace the file name of both the csv file in chrf_score.py 
        In place of predicted.csv, replace it with csv file of predicted output.
        In place of groundTruths.csv, replace it with csv file of ground truths.
    -> Just run the chrf_score.py file to generate the chrf++ score out of 100.
