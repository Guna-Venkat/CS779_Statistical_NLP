Calculate ROUGE Scores for Text Comparison
This script calculates the ROUGE-L (Recall-Oriented Understudy for Gisting Evaluation - Longest Common Subsequence) scores for comparing two text files. ROUGE-L is a metric used in natural language processing and text summarization to assess the quality of generated text by measuring the similarity in the longest common subsequence between the generated and reference text.


Prerequisites
Before running the script, ensure you have the following prerequisites installed:

Python (3.5 or higher)
NLTK (Natural Language Toolkit) library
Rouge library

You can install the required libraries using the following commands:
pip install nltk
pip install rouge


Place the two text files you want to compare in the same directory as the script. Replace the file1_path and file2_path variables with the actual paths to your text files.
